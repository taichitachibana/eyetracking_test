================================================================
  視線追従システム README（統合版）
================================================================

【構成スクリプト】

  GazeFollower.cs 1本のみ

  以前の4スクリプト構成（EyeGazeCombiner / EyeTrackingController /
  HeadFollower / VectorGazePointer）は不要になりました。

----------------------------------------------------------------
【GazeFollower.cs の役割】
----------------------------------------------------------------

  左右の OVREyeGaze から視線データを直接取得し、その中間方向に
  ポインターオブジェクトを追従させる。

  以前の構成で発生していた問題（起動時の位置ズレ、スクリプト間の
  実行順序の競合）をなくすため、1スクリプトに統合した。

----------------------------------------------------------------
【セットアップ手順】
----------------------------------------------------------------

  1. 既存の EyeGazeCombiner / EyeTrackingController /
     HeadFollower / VectorGazePointer を全てシーンから削除する。

  2. 空の GameObject を作成し、名前を「GazeFollower」にする。
     ※ 親子関係はどこでも問題ない。

  3. GazeFollower.cs をその GameObject にアタッチする。

  4. Inspector で以下を設定する。

     Left Eye Gaze  : OVRCameraRig 配下の LeftEyeAnchor に
                      アタッチされている OVREyeGaze コンポーネント
     Right Eye Gaze : OVRCameraRig 配下の RightEyeAnchor に
                      アタッチされている OVREyeGaze コンポーネント
     Pointer Object : 視線に追従させたいオブジェクトの Transform

----------------------------------------------------------------
【Inspector 設定項目】
----------------------------------------------------------------

  Distance             : 目から何メートル先にポインターを置くか（デフォルト 3.0m）
  Smooth Speed         : 追従の滑らかさ（高いほどキビキビ、低いほどなめらか）
                         デフォルト 15。違和感があれば 10〜30 の範囲で調整する。
  Confidence Threshold : 視線データの信頼度の閾値（デフォルト 0.5）
                         これを下回るフレームは更新をスキップする。
                         ポインターが動かない場合は 0.3 に下げて試す。
  Show Debug Ray       : ON にすると視線方向が Scene ビューにシアン色の線で表示される。
                         ポインターとズレがある場合の確認に使う。

----------------------------------------------------------------
【動作の仕組み】
----------------------------------------------------------------

  毎フレーム（LateUpdate）以下を行う。

  1. 左右の OVREyeGaze の Confidence を確認する。
     両方が閾値を下回る場合（視線データ未確定）は何もしない。

  2. 左右の目の位置の中間点と、向きの中間（Slerp）を計算する。

  3. 「中間点 + 中間方向 × Distance」をターゲット座標にする。

  4. 初回のみ Lerp を使わず直接セットする（起動時の画面下への飛び防止）。
     2回目以降は Lerp で滑らかに移動させる。

----------------------------------------------------------------
【トラブルシューティング】
----------------------------------------------------------------

  ● ポインターがまったく動かない
    → Confidence Threshold を 0.3 に下げて試す。
    → Quest Pro の Eye Tracking 権限が有効か確認する。
       （設定 > プライバシー > 視線追跡）
    → Inspector の Left/Right Eye Gaze に正しいコンポーネントが
      設定されているか確認する。

  ● ポインターは動くが視線とズレる
    → Show Debug Ray を ON にして Scene ビューでシアンの線を確認する。
      線の先端にポインターがあれば正常。ズレている場合は
      Left/Right Eye Gaze の参照先が逆になっていないか確認する。
    → Distance の値を調整する（壁や UI の距離に合わせる）。

  ● 動きがカクカクする
    → Smooth Speed を 10〜15 に下げる。
